# Customer Churn Analysis and Prediction Using Python

## Project Overview

This project focuses on analyzing customer churn in a telecommunications company using Python and Machine Learning. The main objective is to identify customers who are likely to leave the company and discover the factors influencing customer churn.

## Dataset

* Dataset: IBM Telco Customer Churn
* Total Records: 7,043 initially
* Records after cleaning: 7,032
* Features: 20 after removing CustomerID

## Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Project Workflow

1. Data Collection
2. Data Understanding
3. Data Cleaning and Preprocessing
4. Exploratory Data Analysis (EDA)
5. Feature Encoding
6. Logistic Regression
7. Random Forest Classification
8. K-Means Clustering
9. Model Evaluation
10. Feature Importance Analysis

## Machine Learning Results

| Model               | Accuracy |
| ------------------- | -------: |
| Logistic Regression |   82.03% |
| Random Forest       |   80.10% |

K-Means Silhouette Score: 0.4517

## Key Findings

* Month-to-month contract customers show higher churn.
* Fiber optic customers have a higher churn count.
* TotalCharges, MonthlyCharges, and tenure are the top three features in Random Forest feature importance.
* Logistic Regression performed better than Random Forest on the evaluation metrics.

## Conclusion

This project demonstrates how data analysis and machine learning can help identify customer churn patterns. The findings can support businesses in developing better customer retention strategies.
